# 잃어버린 세계의 조각 PRD — v6 (처음 오는 사람을 위해)
- 버전: v6 / 작성일: 2026-10-12 / 상태: 확정 (자동 진행 모드 — Claude가 추천안으로 결정)

## 1. 한 줄 요약
v1 성공 기준 "지인 3명이 **설명 없이** 폰으로 끝까지"를 위해, 길을 잃은 사람을 조용히 돕는다.

## 2. 왜
- 지금은 목표 문구가 "무엇을" 할지만 알려 주고 "어디로"는 알려 주지 않는다. 13개 지역·흙더미·심부름·막힌 길이 늘어 처음 하는 사람이 헤맬 곳이 많아졌다.
- 도감·지도·집 같은 기능을 설명 없이 발견하기 어렵다.
- 지인 테스트 결과가 아직 없으므로, 흔히 막히는 지점을 미리 막는다.

## 3. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| Z1 | 길 안내 발자국 | Must | 화면 위 목표 문구를 누르면 지금 목표(보석·조각·제단·다음 길목, 보석이 묻힌 흙더미·심부름 표시)까지 빛나는 발자국이 이어졌다 사라진다. 길이 막혀 있으면 "이 너머에 있다", 다른 지역의 친구가 필요하면 지도 버튼 안내. |
| Z2 | 한 번만 나오는 안내 | Should | 처음 한 번씩: 목표 누르기, 지도 버튼(두 번째 지역에 들어설 때), 도감(처음 아이템을 얻을 때). 한 지역에서 오래(1분 30초) 아무 진전이 없으면 목표 문구가 살짝 흔들린다. 저장 형식 v11. |
| Z3 | 글 다듬기 | Should | 모든 대사·안내 글을 읽고 맞춤법·띄어쓰기·말투를 통일. |

## 4. 테스트
- 자동 플레이 봇 새 게임 → 최종 엔딩(회귀), 13개 지역에서 단계마다 길 안내가 목표에 닿는지 자동 확인.
