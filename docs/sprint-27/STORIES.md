# Sprint 27 — 음악 mp3 사본, 기록 백업 코드, 기록 지키기 안내 (I1~I3)
- 상태: **완료** (2026-10-12, 자동 진행 모드)

## 한 일
- **I1** `tools/convert-music.mjs`: ogg를 풀어(@wasm-audio-decoders/ogg-vorbis) mp3로 다시 저장(@breezystack/lamejs, 96kbps). 12곡 약 7MB. 게임은 `[ogg, mp3]` 중 기기가 틀 수 있는 것을 받는다.
- **I2** 타이틀 "기록 옮기기" → "백업 코드 복사"(클립보드, 막히면 코드를 직접 보여 줌) / "코드로 불러오기"(붙여 넣기 → 옛 버전 고치기 거쳐 적용, 지금 기록이 있으면 한 번 더 묻기). 기록이 없을 때도 "코드로 불러오기". 코드 형식 `LWF1:` + base64(저장 JSON), 약 2.5천 자.
- **I3** 아이폰 사파리(홈 화면 앱이 아닐 때) 타이틀 위 안내, 시작할 때 `navigator.storage.persist()` 요청.

## 테스트에서 찾은 문제
- 첫 mp3 변환이 원본보다 22dB 작게 나옴 → 1초 단위로 보니 앞 3초만 소리가 있고 나머지 무음. lamejs에 큰 덩어리를 넣으면 뒤가 버려짐 → 1152샘플씩 넣도록 수정. 수정 후 12곡 모두 음량 차 0.4dB, 길이 같음, 무음 구간 0.

## 확인
- ogg 못 트는 기기 흉내(device.audio.ogg=false) → winter.mp3를 받아 재생, 이전 곡은 메모리에서 내림.
- 백업 코드: 내보내기 → 불러오기 결과가 원래 기록과 같음, 중간에 줄바꿈·공백이 섞여도 읽힘, 망가진 코드는 거부.
- 자동 플레이 전체 회귀: **미완료.** 이번 세션에서 미리보기 페이지가 계속 숨김 상태가 됨(한 번 돌리는 동안 71번 숨김/보임 전환, document.hidden=true → 브라우저가 화면 갱신을 멈춤). 가장 멀리 간 실행은 새 게임 → 봄 4지역 → 바닷가 마을 터까지 정상.
  - 봇 개선: 시간 초과를 "게임이 실제로 돌아간 시간"으로 재게(창이 멈춘 동안은 시계도 멈춤), 게임 자체가 죽으면 실제 시간 10배에서 "게임이 멈춤"으로 끝냄, 화면 멈춤 시간(stalledSeconds) 기록.
  - 다음 세션에서 창이 보이는 상태로 전체 회귀를 다시 돌릴 것.
