# 잃어버린 세계의 조각 PRD
- 버전: v1 / 작성일: 2026-10-09
- 상태: 확정 (2026-10-09)

## 1. 한 줄 요약
색과 기억이 사라진 흑백 세상을 폰 브라우저에서 탭으로 탐험하며, 펫과 함께 기억의 조각을 찾아 짝맞추기로 복원하면 세상에 색이 돌아오는 30분~1시간 분량의 힐링 수집 게임(첫 계절 1개).

## 2. 문제와 배경
- 사용자는 탐험, 힐링, 수집 요소가 어우러진 게임을 직접 기획하고 처음부터 끝까지 완성해 보고 싶다.
- 요소(탐험·수집·집·펫·퍼즐·계절)가 많아서 따로 놀면 "할 건 많은데 이유가 없는 게임"이 되고, 범위가 폭발해 완성하지 못할 위험이 크다.
- 해결 방향
  - 모든 요소를 **하나의 핵심 루프**로 묶는다.
  - 진행 상황이 UI 숫자가 아니라 **세상의 색**으로 보이게 한다.
  - 첫 버전은 계절 하나로 루프를 끝까지 한 바퀴 돌리는 데 집중한다.

### 핵심 루프
```
탐험(필드·던전) → 기억의 조각 + 보석 발견 → 보석을 제단에 끼움
   → 짝맞추기로 기억 복원(짧은 스토리 장면) → 그 지역에 색이 돌아옴
   → 새 길·구역 해금 → 다음 탐험
```
- 보석 = 복원의 열쇠. 지역마다 보석 1개를 찾아 제단에 끼워야 그 지역의 기억 퍼즐이 열린다.
- 짝맞추기 = 기억을 되살리는 의식. 카드 그림이 그 기억 장면의 조각이다.
- 펫(여우) = 탐험 도구. 땅 파기로만 열리는 지하 길과 숨은 보물이 있다.
- 수집 도감 = 여정의 기록. 다음 버전에서는 집 전시로 이어진다.

## 3. 대상 사용자
| 페르소나 | 상황 | 원하는 것 |
|---|---|---|
| 힐링 게이머 (지인) | 출퇴근이나 쉬는 시간에 폰으로 짧게 플레이 | 압박 없이 천천히 탐험하고 모으는 즐거움, 귀여운 펫 |
| 제작자 본인 | 코딩 경험은 거의 없고 Claude와 함께 제작, 주 3~5시간 | 작아도 끝까지 완성된 게임, 폰에서 바로 확인 |

## 4. 핵심 사용 시나리오
1. 지인이 링크를 받아 폰 브라우저(세로 화면)로 접속하고, 타이틀 화면에서 시작을 누른다.
2. 짧은 도입 장면에서 세상의 색과 기억이 사라졌다는 이야기를 본다. 봄의 들판이 흑백이다.
3. 탭으로 캐릭터를 움직여 첫 지역을 탐험하다가 빛나는 기억의 조각과 보석을 찾는다.
4. 지역의 제단에 보석을 끼우면 짝맞추기 퍼즐이 열리고, 다 맞추면 기억 장면(그림 1장 + 대사 2~4줄)이 나온다.
5. 그 지역에 색이 번지듯 돌아오고, 막혀 있던 길이 열린다.
6. 도중에 여우를 만나 동료로 삼고, 땅 파기로 숨은 길과 보석을 찾는다.
7. 동굴·유적 던전에서 마지막 기억을 복원하면 봄 전체에 색이 돌아오고 엔딩을 본다.
8. 중간에 앱을 닫아도 다시 접속하면 이어서 플레이한다.

## 5. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| F1 | 탭 이동 필드 탐험 | Must | 탭한 곳으로 캐릭터가 길을 찾아 이동하고, 2~3개 지역을 오갈 수 있다. 벽·물 등 막힌 곳은 지나갈 수 없다. |
| F2 | 흑백 → 색 복원 연출 | Must | 시작 시 화면 전체가 흑백이고, 지역을 복원하면 그 지역만 색이 서서히 돌아온다. 복원 상태가 저장된다. |
| F3 | 기억의 조각·보석 수집 | Must | 맵에 배치된 기억 조각 4~6개와 지역별 보석을 발견해 획득할 수 있고, 획득 현황이 표시된다. |
| F3a | 보석 제단 | Must | 지역마다 제단이 있고, 그 지역 보석을 끼우면 기억 퍼즐이 열린다. 보석이 없으면 힌트 문구가 나온다. |
| F4 | 짝맞추기 퍼즐 | Must | 제단에서 기억 조각을 사용하면 퍼즐이 열린다. 카드를 뒤집어 짝을 맞추고, 다 맞추면 클리어된다. 실패 페널티는 없다(힐링 톤). 뒤로 갈수록 카드 수가 늘어난다. |
| F5 | 기억 장면(스토리) | Must | 퍼즐을 클리어하면 장면 그림 1장과 대사 2~4줄이 나오고, 도감에서 다시 볼 수 있다. 도입·엔딩 장면도 있다. |
| F6 | 복원에 따른 해금 | Must | 지역을 복원하면 다음 지역으로 가는 길이 열린다. 해금 순서대로 진행하면 엔딩까지 막히지 않는다. |
| F7 | 펫: 여우 (땅 파기) | Must | 여우를 만나 동료로 삼으면 플레이어를 따라다닌다. 흙더미 같은 지정 지점에서 땅 파기를 쓸 수 있고, 땅 파기로만 열리는 길이나 보물이 1곳 이상 있다. |
| F8 | 동굴·유적 던전 1곳 | Must | 필드와 분리된 구역으로, 땅 파기가 필요한 구간이 있다. 마지막 기억 조각과 보석이 여기 있다. |
| F9 | 희귀 아이템 + 수집 도감 | Must | 맵 곳곳의 희귀템을 얻을 수 있다. 도감에서 보석·희귀템·기억 장면을 볼 수 있고, 얻은 것은 컬러로, 못 얻은 것은 실루엣으로 보인다. |
| F10 | 자동 저장·이어하기 | Must | 진행(위치, 복원 지역, 수집품, 펫)이 기기에 자동 저장되고, 다시 접속하면 이어진다. |
| F11 | 타이틀·엔딩 | Must | 타이틀 → 플레이 → 엔딩 → 타이틀로 이어지는 전체 흐름이 끊김 없이 동작한다. |
| F12 | 모바일 화면 대응 (세로) | Must | 안드로이드 크롬과 iOS 사파리에서 세로 화면에 맞게 표시되고, 한 손 터치로 모든 조작이 가능하다. |
| F13 | 사운드(BGM·효과음) | Should | 지역별 잔잔한 BGM, 획득·복원 효과음이 있고 음소거 버튼이 있다. |

## 6. 비기능 요구사항
- **성능**: 보급형 안드로이드 폰 브라우저에서 30fps 이상, 첫 로딩 5초 이내(일반 LTE·와이파이)
- **데이터**: 진행 데이터는 기기 브라우저 저장소에만 저장한다. 서버와 로그인은 없다.
- **개인정보**: 수집하는 개인정보는 없다. 분석 도구도 넣지 않는다.
- **호환성**: 안드로이드 크롬, iOS 사파리 최신 버전
- **라이선스**: 사용한 무료 에셋의 출처와 라이선스를 크레딧 화면과 `CREDITS.md`에 표기한다.
- **운영**: 무료 정적 호스팅에 배포하고, 링크 하나로 공유한다.

## 7. 기술 스택과 제약
- **추천 스택** (확정 필요)
  - 엔진: Phaser 3 (2D 웹게임 엔진, 자료 풍부, 모바일 브라우저 지원)
  - 언어·빌드: JavaScript 또는 TypeScript + Vite
  - 맵 제작: Tiled (무료 타일맵 에디터)
  - 배포: GitHub Pages (무료)
- **아트**: 무료 픽셀 에셋 팩. 그림체 통일을 위해 필드·동굴·동물·아이템이 한 팩(또는 같은 작가 시리즈)에 있는 것을 우선한다.
- **흑백 표현**: 컬러 에셋에 흑백(채도) 필터를 적용하는 방식. 흑백용 그림을 따로 만들지 않는다.
- **인원**: 사용자 + Claude. 코드는 Claude가 주로 작성하고, 사용자는 기획·폰 테스트·피드백·계정 생성(GitHub 등)을 맡는다.
- **시간**: 주 3~5시간
- **예산**: 0원 목표(무료 에셋·호스팅). 유료 에셋은 필요할 때 따로 결정한다.

## 9. 가정과 리스크
### 가정
- 흑백 필터와 지역별 색 복원 연출이 모바일 브라우저에서 충분히 부드럽게 동작한다.
- 필요한 요소(필드·동굴·동물·보석)를 담은 통일된 무료 픽셀 에셋 팩을 구할 수 있다.
- 짝맞추기 4~6회가 반복돼도 카드 그림(기억 장면)과 난이도 변화로 지루하지 않다.

### 리스크
| 리스크 | 영향 | 대응 |
|---|---|---|
| 범위 폭발 | 완성 실패 | Won't 목록을 지키고, 첫 스프린트에서 가장 얇은 전체 흐름부터 관통시킨다. |
| 에셋 그림체 불일치 | 완성도 저하 | 개발 초기에 에셋 팩을 먼저 확정한다. |
| 흑백·색 복원의 모바일 성능 | 끊김, 발열 | 초기 스프린트에서 실제 폰으로 먼저 검증한다. |
| 짝맞추기 반복의 지루함 | 재미 저하 | 카드 수 증가, 장면별 카드 그림, 시간 제한 없음으로 부담을 줄인다. |
| iOS 사파리의 저장 데이터 삭제 정책 (홈 화면에 설치하지 않으면 7일 미사용 시 삭제될 수 있음) | 진행 소실 | 플레이 시간이 짧아서 영향이 작다. PWA 설치를 안내한다. |
| 사용자가 코딩·배포 경험이 없음 | 막혔을 때 혼자 해결하기 어려움 | 배포·테스트 절차를 단계별 문서로 남긴다. |

## 10. 열린 질문
1. **에셋 팩 선정**: 봄 필드, 동굴·유적, 여우, 보석·아이템이 한 팩(또는 같은 작가 시리즈)에 있는 후보를 찾아 비교한 뒤 결정한다. 세로 화면이라 타일 크기(16px/32px)도 같이 정한다.
2. **장면 그림**: 기억 장면 그림(4~6장)과 짝맞추기 카드 그림을 어떻게 구할지 (에셋 조합 / AI 생성 / 직접)
3. **기술 스택**: Phaser 3 + Vite + GitHub Pages 추천안으로 확정할지
