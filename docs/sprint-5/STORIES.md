# Sprint 5 스토리 — 동굴 유적과 엔딩: 처음부터 끝까지
- 상태: **스프린트 완료** (2026-10-10, 자동 진행 모드 — 폰 확인 대기)
- 스프린트 목표: 타이틀 → 도입 글 → 들판·숲길·언덕 복원 → 잊힌 유적(던전) → 마지막 기억 → 엔딩 → 요약 화면까지, 처음부터 끝까지 플레이할 수 있다.
- 관련 기능: F8, F11(완성), 기억 조각 4개 배치(PRD 4~6개)

## 설계 결정 (가정)
- 던전 = **잊힌 유적**(24×36, 어두운 화면). 꽃 언덕을 복원하면 북쪽 길목의 시든 나무가 사라져 들어갈 수 있다.
- 던전 흐름: 입구 위 **돌무더기를 너구리가 파서 길을 냄**(F8 땅 파기 구간) → 옆방 흙더미에서 **은빛 열쇠** → 잠긴 문 안의 **붉은빛 보석** → 돌집 앞 제단 → 카드 10장 퍼즐 → 마지막 기억("어린 날의 나") → 엔딩.
- 기억 조각은 지역 3 + 유적 1 = **4개**. 희귀 아이템은 은빛 열쇠를 더해 6개.
- 저장 형식 v4(열린 길 기록).

## S-5.1: 유적 지도 — 완료
- 유적 타일(이끼 낀 돌집·기둥·석상·돌무더기), 짙은 흙바닥, 소나무 숲 테두리. 지도 생성기에 "여러 칸 구조물 찍기", "바탕 땅 종류", 장벽 종류(시든 나무·돌무더기·잠긴 문) 추가.

## S-5.2: 땅 파기로 길 열기 · 열쇠와 잠긴 문 — 완료
- Given 돌무더기 앞 흙더미 When 너구리와 다가가면 Then "무너진 돌 틈을 파서 길을 냈다", 돌무더기가 사라진다.
- Given 잠긴 문 When 열쇠가 없으면 Then "어딘가에 열쇠가 있을 것 같다" / When 있으면 Then "은빛 열쇠로 문을 열었다".

## S-5.3: 어두운 곳 연출 — 완료
- 유적에서는 화면 가장자리가 어둡고 가운데만 밝다(지도 속성 dark).

## S-5.4: 도입과 엔딩 — 완료
- 새 게임: 도입 글 4줄 → 들판. 네 지역을 모두 되찾으면 엔딩 글 4줄 → "봄을 되찾았다" 요약 화면(되찾은 기억·보석·희귀 아이템 수).
- 기억 장면 글이 두 줄로 넘어갈 때 겹치던 문제 수정(문장 높이에 맞춰 배치).
