# Sprint 5 회고 — 동굴 유적과 엔딩
- 기간: 2026-10-10 (자동 진행 모드)
- 결과: **콘텐츠 완성(content complete)**. 처음부터 끝까지 플레이 가능. 폰 확인 대기.

## 잘된 것
- 장벽을 "어떻게 열리는가(복원·땅 파기·열쇠)"와 "어떻게 보이는가(시든 나무·돌무더기·문)"로 나눠, 던전 퍼즐을 지도 데이터만으로 짤 수 있게 됐다.
- 지도 자동 검사로 "열쇠가 문 안쪽에 있다" 같은 진행 불가 실수를 배포 전에 막는다.
- 마지막 기억을 주인공 자신의 이야기로 두어, 도입("무언가 소중한 것을 잊어버렸다")과 엔딩이 이어진다.

## 막힌 것
- 기억 장면의 긴 문장이 겹쳐 보이는 문제 → 문장 높이에 맞춰 배치.

## 남은 것 / 다음 스프린트(6: 다듬기)
- 실제 플레이 시간 측정 필요(사용자). 예상: 걷기·탐험 15~25분 + 퍼즐 5회. 30분에 못 미치면 탐험 요소(숨은 흙더미, 지역 크기)를 늘린다.
- 기억 장면 그림(지금은 얼굴 + 글)과 조각 모양(도형) 교체.
- 사운드(팩의 음악·효과음), 홈 화면 설치(PWA), 너구리 쓰다듬기.
- 처음 하는 사람을 위한 안내: "화면을 탭해서 이동" 힌트, 목표 안내(HUD).
