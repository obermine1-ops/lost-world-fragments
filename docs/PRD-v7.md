# 잃어버린 세계의 조각 PRD — v7 (폰에서 가볍게)
- 버전: v7 / 작성일: 2026-10-12 / 상태: 확정 (자동 진행 모드 — Claude가 측정 결과로 결정)

## 1. 한 줄 요약
폰에서 꺼지지 않고, 데이터를 덜 쓰고, 소리가 고르게 들리게 한다.

## 2. 측정 (개발 PC, 2026-10-12)
- 화면 그리기: 13개 지역 모두 한 프레임 CPU 0.5~0.7ms(95% 1.8ms 이하) → 넉넉함. GPU는 폰에서 확인 필요.
- **음악: 시작하자마자 12곡 14MB를 모두 받고, 풀어서 메모리에 215MB** → 저사양 폰에서 브라우저가 탭을 끌 수 있음. 가장 큰 문제.
- 음량: 곡마다 평균 -14 ~ -28dB로 13dB 차이. 겨울은 색을 되찾으면 음악이 확 작아짐(-15.7 → -27.8dB). 흙더미 효과음이 특히 작음.

## 3. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| P1 | 음악 필요할 때만 | Must | 지금 필요한 곡만 받고, 다 쓴 곡은 메모리에서 내림. 메모리의 음악은 한 곡(최대 약 26MB). |
| P2 | 소리 균형 | Must | 곡·효과음마다 측정한 배율로 비슷한 크기. |
| P3 | 소리 설정 3단계 | Should | 소리 버튼: 소리 켜짐 → 효과음만 → 소리 꺼짐. 효과음만·꺼짐이면 음악 파일을 받지 않음. 예전 "꺼짐" 설정은 그대로 이어짐. |
