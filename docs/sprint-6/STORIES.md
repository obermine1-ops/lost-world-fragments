# Sprint 6 스토리 — 다듬기
- 상태: **스프린트 완료** (2026-10-10, 자동 진행 모드 — 폰 확인 대기)
- 스프린트 목표: 남에게 보여 줄 수 있는 버전. 소리, 홈 화면 설치, 처음 하는 사람을 위한 안내.
- 관련 기능: F13(사운드), F14(PWA), F15(펫 교감), F12(성능)

## S-6.1: 음악과 효과음 (F13) — 완료
- 팩의 음악 5곡: 타이틀(Quiet), 흑백 지역(Melancholia), 복원된 지역(Peaceful), 유적(Ruins), 엔딩(End Theme). 색이 돌아오면 음악도 바뀐다(부드럽게 교차).
- 효과음 11종: 줍기·보석·카드 뒤집기·짝 맞춤·퍼즐 완료·색 복원·땅 파기·문 열림·너구리·버튼·기억 장면.
- 음악(약 4MB)은 게임 시작 후 뒤에서 불러와 첫 화면이 늦어지지 않는다.
- "소리 켜짐/꺼짐" 버튼(타이틀·게임), 설정은 기기에 기억.
- 주의: 음악은 ogg 형식이라 **오래된 아이폰(사파리)에서는 음악이 안 나올 수 있다**(효과음 wav는 정상). 지인 테스트에서 확인.

## S-6.2: 홈 화면 설치 (F14) — 완료
- 앱 이름·아이콘(주인공 + 너구리, 흑백 → 봄빛 배경), 세로 고정, 전체 화면.
- 서비스 워커: 항상 최신 파일을 먼저 받고, 인터넷이 끊기면 보관본으로 실행.

## S-6.3: 처음 안내와 목표 표시 — 완료
- 새 게임 첫 화면: "👆 가고 싶은 곳을 탭해 보세요"(한 번 탭하면 사라짐).
- HUD 아래 목표 한 줄: 보석 찾기 → 조각 찾기 → 제단 → 다음 장소. 언덕에서 너구리가 없으면 "땅을 파는 친구가 필요하다".
- 흙더미 문구도 너구리 힌트로 변경("땅을 잘 파는 친구가 있으면 좋을 텐데").

## S-6.4: 너구리 쓰다듬기 (F15) — 완료
- 너구리를 탭하면 꿈틀하며 하트가 떠오른다.

## S-6.5: 퍼즐 카드 그림 — 완료
- 도형 → 봄꽃(해바라기·빨간 꽃·데이지·클로버)과 수정 그림.

## S-6.6: 성능·크레딧 — 완료
- 배포본 첫 화면 약 1초(PC 기준). 폰 체감은 확인 대기.
- 타이틀 아래에 그림·음악 출처 표기(CC0, 감사 표시).
