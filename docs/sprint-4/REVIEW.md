# Sprint 4 회고 — 너구리와 도감
- 기간: 2026-10-10 (자동 진행 모드)
- 결과: 스토리 5개 구현·배포. 폰 확인 대기.

## 잘된 것
- "다가가면 한 번 반응하는 지점(Spot)"으로 제단·너구리·흙더미 처리를 하나로 묶어 코드가 단순해졌다.
- 동료가 된 너구리만 컬러로 보이는 연출이 "색을 되찾는 여행" 이야기와 잘 맞는다.
- 도감에서 기억 장면을 다시 볼 수 있어, 모은 것의 의미가 생겼다.

## 막힌 것
- 너구리가 흙더미 앞에서 "도착"을 인정받지 못하고 멈춰 있는 버그(소수점 오차) → 도착 판정에 여유를 둬서 해결.
- 개발 서버가 코드 변경 시 페이지를 새로 불러오면서 테스트 중이던 진행 상태가 초기화됨 → 개발 모드에서 `window.progress`로 상태를 직접 넣어 테스트.

## 다음 스프린트(5: 동굴 유적과 엔딩)에 반영할 것
- 던전은 너구리 땅 파기로 길을 여는 구간을 넣는다(F8 완료 기준).
- 은빛 열쇠를 던전 보상/열쇠로 쓴다.
- 엔딩을 "세 지역 복원" → "던전의 마지막 기억까지"로 옮긴다. 도입 장면(세상이 흑백이 된 이유)도 넣는다.
- 플레이 시간을 늘리기 위해 조각을 지역당 1개 → 지역 + 던전 합계 4~6개로 맞춘다.
