# Sprint 4 스토리 — 너구리와 도감
- 상태: **스프린트 완료** (2026-10-10, 자동 진행 모드 — Claude가 작성·구현, 폰 확인 대기)
- 스프린트 목표: 들판에서 외로운 너구리를 만나 동료로 삼고, 함께 다니며 흙더미를 파서 숨은 보석·희귀 아이템을 찾는다. 도감에서 모은 보석·아이템·기억을 본다.
- 관련 기능: F7, F9

## 설계 결정 (가정)
- 너구리는 들판 A 연못 아래쪽(7,32)에서 웅크리고 있다. 다가가면 동료가 되고, **동료가 되는 순간 너구리에게 먼저 색이 돌아온다.**
- 너구리는 장애물과 부딪히지 않고 따라온다(작은 동물이라 덤불 사이로 빠져나간다는 설정 — 길 막힘 방지).
- 흙더미 6곳: 들판 1(피리), 숲길 2(편지·모래시계), 언덕 3(**보랏빛 보석**·그림책·꽃씨). 언덕 보석은 너구리 없이는 찾을 수 없다.
- 희귀 아이템 5종(에셋 팩 아이콘): 작은 대나무 피리, 빛바랜 편지, 멈춘 모래시계, 그림책, 꽃씨 주머니. 은빛 열쇠는 Sprint 5 던전용으로 아껴 둠.
- 저장 형식 v3 (v2 기록 자동 변환).

## S-4.1: 너구리를 만나 동료로 — 완료
- Given 들판의 회색 너구리 When 다가가면 Then 컬러로 바뀌며 따라오기 시작하고, 안내 문구 2개가 나온다. 지역을 옮겨도 함께 온다. 저장된다.

## S-4.2: 따라다니기 — 완료
- 플레이어 뒤 약 18px에서 따라오고, 멀어지면 조금 빨리 온다. 좌우 방향 전환, 걷기 2프레임.

## S-4.3: 흙더미 파기 — 완료
- Given 너구리 없이 흙더미에 다가가면 Then "무언가 묻혀 있는 것 같다".
- Given 너구리와 함께 다가가면 Then 너구리가 달려가 파내고(흙먼지), 보석 또는 아이템이 튀어나와 자동으로 얻는다. 파 본 곳은 다시 생기지 않는다.

## S-4.4: 수집 도감 — 완료
- 화면 오른쪽 위 "도감" 버튼. 보석 3 · 희귀 아이템 5 · 되찾은 기억 3, 찾은 것은 컬러/못 찾은 것은 실루엣, 칸을 누르면 설명, 기억 칸은 장면 다시 보기.

## S-4.5: 확인 — 완료 (브라우저)
- 새 게임 → 너구리 합류 → 들판 흙더미(피리) → 도감 확인 → 언덕 흙더미(보석) 확인. 폰 확인은 대기.
