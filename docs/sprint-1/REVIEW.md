## 잘된 것
- 가장 큰 기술 리스크(모바일 흑백 효과)를 첫 스프린트에서 해소했다.
- 푸시하면 자동 배포되는 흐름 덕분에 매 스토리를 폰으로 바로 확인했다.
- 도형만으로도 핵심 루프의 감정("색이 돌아와서 기분 좋다")이 전달됐다.

## 막힌 것
- 첫 푸시 때 Claude 세션의 셸에서 GitHub 로그인 창을 못 띄워 사용자 터미널 탭으로 진행했다. (이후엔 저장된 인증으로 해결)
- Claude 앱이 Node.js 설치 전에 켜져 있어 PATH 문제 → 개발 서버를 node.exe로 직접 실행
- 장애물에 닿으면 바로 멈추게 했더니 나무에 달라붙음 → 미끄러짐 + 진척 없을 때 멈춤으로 수정
- 브라우저 패널의 모바일 크기 캡처가 실제 배치와 다르게 보임 → 실제 폰 확인을 기준으로 삼음

## 새로 알게 된 것
- 화면 전체(카메라)에 흑백 효과를 걸면 조각·버튼까지 흑백이 된다. "흑백 세상에서 조각만 빛남"과 지역별 복원을 위해 Sprint 3에서 효과를 분리해야 한다.
- 진행 속도의 병목은 코드가 아니라 사용자의 폰 확인·피드백 시간이다. 스프린트를 기간이 아닌 목표 단위로 운영하기로 했다.
