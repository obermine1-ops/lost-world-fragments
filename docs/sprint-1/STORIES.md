# Sprint 1 스토리 — 걷는 뼈대
- 상태: 확정 (2026-10-09)
- 스프린트 목표: 폰으로 링크를 열면 타이틀 → 흑백 들판(도형) → 탭 이동 → 기억 조각 줍기 → 카드 4장 짝맞추기 → 색이 돌아옴 → "끝" 화면까지 한 바퀴 돈다.
- 투입 가능 시간: 6~10시간 (사용자 기준)
- 예상 규모 기준 (사용자 시간): S = 30분~1시간, M = 1~2시간
- 코드 작성은 Claude가 맡는다. 사용자 시간은 설치·계정 생성·폰 확인·피드백에 쓴다.
- 테스트 기기: 사용자의 안드로이드 폰(크롬). iOS 사파리는 Sprint 3 중간 테스트 때 아이폰 쓰는 지인으로 확인한다.

## S-1.1: 개발 환경 준비
- 스토리: 제작자로서 내 PC에서 게임 프로젝트를 실행해 보고 싶다, 그래서 이후 작업을 바로 확인할 수 있다.
- 관련 기능: (기반)
- 인수 조건:
  - Given Node.js가 설치된 PC에서 When 실행 명령을 하나 입력하면 Then 브라우저에 Phaser 게임 화면("Hello" 문구)이 뜬다.
  - Given 코드를 고치고 저장했을 때 When 브라우저를 보면 Then 새로고침 없이 바뀐 화면이 보인다.
- 세부 작업:
  - [x] Node.js(LTS) 설치 (winget, v24.20.0)
  - [x] Phaser 3 + Vite + TypeScript 프로젝트 생성 (Phaser 3.90, Vite 8, TypeScript 7)
  - [x] 게임 화면을 세로 비율(360×640, 9:16, FIT)로 설정
  - [x] `README.md`에 실행 방법 기록
  - [x] git 저장소 초기화 (main 브랜치, 첫 커밋은 S-1.2에서)
- 예상 규모: S
- 의존: 없음
- 상태: **완료** (2026-10-09) — 모바일 크기(375×812) 브라우저에서 화면 표시, 저장 시 자동 새로고침 확인, 빌드 통과

## S-1.2: GitHub Pages 배포와 폰 접속
- 스토리: 제작자로서 내 폰에서 링크 하나로 게임을 열고 싶다, 그래서 매번 실제 기기에서 확인하고 지인에게 보낼 수 있다.
- 관련 기능: F12, (배포 기반)
- 인수 조건:
  - Given GitHub에 코드를 올렸을 때 When 몇 분 기다리면 Then 자동으로 배포되어 GitHub Pages 링크에 최신 버전이 뜬다.
  - Given 사용자의 안드로이드 폰(크롬) When 링크를 열면 Then "Hello" 화면이 세로 화면에 맞게 보인다.
  - Given 배포 방법을 잊었을 때 When `docs/HOW-TO-DEPLOY.md`를 보면 Then 순서대로 따라 할 수 있다.
- 세부 작업:
  - [x] GitHub 계정 새로 만들기 (obermine1-ops)
  - [x] 저장소 생성(lost-world-fragments, Public), 코드 올리기
  - [x] GitHub Actions로 자동 배포 설정 — 첫 배포 성공 (https://obermine1-ops.github.io/lost-world-fragments/)
  - [x] 폰에서 접속 확인 (사용자 안드로이드 크롬, 정상 표시)
  - [x] `docs/HOW-TO-DEPLOY.md` 작성
- 예상 규모: M
- 의존: S-1.1
- 상태: **완료** (2026-10-09)

## S-1.3: 화면 흐름 — 타이틀 → 게임 → 끝
- 스토리: 플레이어로서 시작 버튼을 눌러 게임에 들어가고 끝 화면을 보고 싶다, 그래서 게임의 처음과 끝이 있다고 느낀다.
- 관련 기능: F11(얇게), F12
- 인수 조건:
  - Given 게임을 열면 When 타이틀 화면에서 "시작"을 탭하면 Then 게임 화면으로 넘어간다.
  - Given 게임 화면에서 When (임시) 끝 조건이 되면 Then "끝" 화면이 나오고, 탭하면 타이틀로 돌아간다.
  - Given 폰을 세로로 들었을 때 Then 모든 화면이 잘리지 않고 보인다.
- 세부 작업:
  - [x] 타이틀 / 게임 / 끝 장면(Scene) 3개 만들기
  - [x] 장면 전환 (페이드 0.4초, 전환 중 중복 탭 무시)
  - [x] 다양한 폰 비율 대응(여백 처리 — FIT 모드로 비율 유지, 남는 곳은 배경색)
- 예상 규모: S
- 의존: S-1.1
- 상태: **완료** (2026-10-09) — 브라우저에서 두 바퀴 확인, 사용자 폰에서 흐름·버튼 크기·잘림 확인

## S-1.4: 흑백 → 컬러 전환 검증 (리스크 확인)
- 스토리: 제작자로서 폰에서 흑백 화면이 부드럽게 컬러로 돌아오는 걸 보고 싶다, 그래서 이 게임의 핵심 연출이 기술적으로 가능한지 일찍 안다.
- 관련 기능: F2(얇게)
- 인수 조건:
  - Given 컬러 도형으로 채운 게임 화면 When 시작하면 Then 화면 전체가 흑백으로 보인다.
  - Given 흑백 상태 When (임시) 테스트 버튼을 탭하면 Then 2~3초에 걸쳐 색이 서서히 돌아온다.
  - Given 사용자의 폰 When 전환을 여러 번 반복하면 Then 눈에 띄는 끊김이 없다(체감 확인).
- 세부 작업:
  - [x] 화면 전체에 흑백(채도) 효과 적용 — 카메라 postFX ColorMatrix (`src/worldColor.ts`)
  - [x] 채도를 0 → 1로 서서히 바꾸는 연출 (2.5초)
  - [x] 화면에 FPS 표시(개발용)
  - [x] 폰에서 확인 (사용자: 부드럽게 전환, 반복해도 괜찮음)
- 상태: **완료** (2026-10-10) — 핵심 기술 리스크(모바일 흑백 효과) 해소
- 메모: 지금은 카메라 전체에 효과를 거는 방식이라 UI(버튼)까지 흑백이 된다. 지역별 복원(Sprint 3)과 UI 분리는 그때 확장한다.
- 예상 규모: M
- 의존: S-1.2 (폰 확인), S-1.3

## S-1.5: 흑백 들판과 탭 이동
- 스토리: 플레이어로서 가고 싶은 곳을 탭하면 캐릭터가 걸어가길 원한다, 그래서 한 손으로 편하게 탐험할 수 있다.
- 관련 기능: F1(얇게)
- 인수 조건:
  - Given 들판(도형 맵, 화면보다 넓음) When 빈 곳을 탭하면 Then 캐릭터(동그라미)가 그곳으로 걸어간다.
  - Given 이동 중 When 다른 곳을 탭하면 Then 새 목적지로 방향을 바꾼다.
  - Given 장애물(네모) When 장애물에 부딪히면 Then 통과하지 못하고 멈춘다. (돌아가는 길 찾기는 Sprint 2)
  - Given 캐릭터가 움직이면 Then 카메라가 따라간다.
- 세부 작업:
  - [x] 도형으로 된 들판 맵(720×1280), 연못·나무·바위 장애물
  - [x] 탭 위치로 이동, 탭한 곳 표시
  - [x] 장애물 충돌 (비스듬히 닿으면 미끄러져 비켜 가고, 정면으로 막히면 멈춤)
  - [x] 카메라 따라가기
  - [ ] 폰에서 조작감 확인 (사용자)
- 상태: 구현·배포 완료 (2026-10-10), 폰 확인 대기
- 예상 규모: M
- 의존: S-1.3

## S-1.6: 기억 조각 줍기
- 스토리: 플레이어로서 들판에서 빛나는 조각을 발견해 줍고 싶다, 그래서 탐험한 보람을 느낀다.
- 관련 기능: F3(얇게)
- 인수 조건:
  - Given 들판에 반짝이는 조각(도형) When 캐릭터가 닿으면 Then 조각이 사라지고 "기억의 조각을 찾았다" 문구가 나온다.
  - Given 조각을 주웠을 때 Then 화면 위쪽에 획득 개수(0/1 → 1/1)가 보인다.
- 세부 작업:
  - [ ] 조각 오브젝트와 반짝임 효과
  - [ ] 획득 처리와 문구
  - [ ] 획득 개수 표시(HUD)
- 예상 규모: S
- 의존: S-1.5

## S-1.7: 카드 4장 짝맞추기
- 스토리: 플레이어로서 카드를 뒤집어 짝을 맞추고 싶다, 그래서 기억을 되살리는 과정을 직접 해본다.
- 관련 기능: F4(얇게)
- 인수 조건:
  - Given 퍼즐 화면(카드 4장, 2쌍, 뒷면) When 카드 1장을 탭하면 Then 앞면이 보인다.
  - Given 2장을 뒤집었을 때 When 같은 그림이면 Then 그대로 열려 있고, 다르면 잠시 뒤 다시 뒤집힌다.
  - Given 모든 짝을 맞추면 Then "기억이 돌아왔다" 문구와 함께 퍼즐이 끝난다.
  - 실패 횟수 제한이나 시간 제한은 없다.
- 세부 작업:
  - [ ] 퍼즐 장면, 카드 무작위 배치
  - [ ] 뒤집기 연출과 짝 판정
  - [ ] 클리어 처리
  - [ ] 세로 화면에서 손가락으로 누르기 편한 카드 크기
- 예상 규모: M
- 의존: S-1.3

## S-1.8: 한 바퀴 연결과 폰 데모
- 스토리: 플레이어로서 조각을 줍고 퍼즐을 풀면 세상에 색이 돌아오는 걸 보고 싶다, 그래서 이 게임의 핵심 경험을 처음부터 끝까지 느낀다.
- 관련 기능: F1·F2·F3·F4·F11 연결
- 인수 조건:
  - Given 조각을 주운 상태 When 조각 획득 직후 Then 퍼즐 화면으로 넘어간다.
  - Given 퍼즐을 클리어하면 When 들판으로 돌아오면 Then 흑백이던 들판에 색이 서서히 돌아온다.
  - Given 색이 다 돌아오면 Then 잠시 뒤 "끝" 화면이 나온다.
  - Given 사용자의 폰 When 타이틀부터 끝까지 진행하면 Then 막힘 없이 한 바퀴 돈다.
- 세부 작업:
  - [ ] 조각 → 퍼즐 → 들판 복귀 → 색 복원 → 끝 연결
  - [ ] 임시 테스트 버튼·FPS 표시 숨기기(개발 모드에서만)
  - [ ] 배포 후 폰으로 전체 데모 (사용자)
  - [ ] 스프린트 종료 회고 준비 (잘된 것·막힌 것 메모)
- 예상 규모: S
- 의존: S-1.4, S-1.6, S-1.7
