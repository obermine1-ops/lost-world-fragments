# 잃어버린 세계의 조각 PRD — v5 (추억 정리)
- 버전: v5 / 작성일: 2026-10-12 / 상태: 확정 (자동 진행 모드 — Claude가 추천안으로 결정)

## 1. 한 줄 요약
이야기는 v4에서 닫혔다. v5는 **엔딩 후에도 머물고 싶은 세상**을 만든다: 13개 지역을 한 번에 오가는 세계 지도, 놓친 반딧불을 찾게 돕는 장치, 모두 모으면 받는 마지막 선물.

## 2. 왜
- 최종 엔딩 뒤 "이어하기"를 누르면 별빛 언덕(13번째 지역)에서 시작한다. 집(봄 들판)까지 걸어서 12개 지역을 거슬러 가야 한다.
- 반딧불 39마리는 숨어 있어 놓치기 쉽고, 어디서 놓쳤는지 알 방법이 없다.
- 지인 플레이테스트 전에 완성도를 높인다(새 계절·새 펫 없이 범위 통제).

## 3. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| Y1 | 세계 지도·빠른 이동 | Must | 화면의 "지도" 버튼 → 계절별 지역 목록. 되찾은 지역과 지금 가야 할 지역은 눌러서 바로 이동, 아직 못 간 곳은 "???". "나의 집"(봄 들판을 되찾은 뒤) 바로 가기. |
| Y2 | 반딧불 찾기 도우미 | Should | 지도에 지역별 반딧불 n/3. 색을 되찾은 지역에서는 남은 반딧불 가까이 가면 반짝이는 소리·빛으로 알려 준다. |
| Y3 | 완전 수집 선물 | Should | 반딧불 39 + 희귀 아이템 15를 모두 모으면 특별 가구와 짧은 글, 타이틀·도감에 "완전 수집" 표시. |
| Y4 | 엔딩 후 이어하기 | Must | 최종 엔딩을 본 뒤 "이어하기"는 나의 집 앞에서 시작(한 번). |

## 4. 테스트
- 지도 검사 13개 지역, 자동 플레이 봇 새 게임 → 최종 엔딩 완주(회귀).
- 빠른 이동: 브라우저에서 기록을 만들어 모든 지역 이동·집 바로 가기 확인.

## 5. 가정
- 빠른 이동은 처음부터 쓸 수 있다(되찾은 지역만 가므로 진행을 건너뛰지 않음).
- 빠른 이동 도착 지점: 지도의 시작 지점, 없으면 앞 지역에서 들어오는 길목. 봄 들판은 집 앞.
