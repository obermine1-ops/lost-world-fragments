## S-2.2: 첫 번째 진짜 지역 (봄 들판 A)
- 스토리: 플레이어로서 도형이 아닌 진짜 픽셀 그림 들판을 걷고 싶다, 그래서 게임 세계에 들어온 느낌을 받는다.
- 관련 기능: F1
- 인수 조건:

  - Given 나무·바위·물 타일 When 캐릭터가 부딪히면 Then 지나가지 못한다(충돌 정보는 맵 데이터에서 읽는다).
  - Given 폰에서 플레이 When 들판을 걸으면 Then 그림이 흐릿하지 않고 픽셀이 또렷하다.
- 세부 작업:

- 상태: 구현·배포 완료 (2026-10-10), 폰 확인 대기. 주인공은 정지 그림(애니메이션은 S-2.3)

## S-2.5: 지역 2~3개와 지역 이동

  - Given 지역 B When 반대 출구로 가면 Then 지역 A의 해당 출구 앞으로 돌아온다.

## S-2.6: 자동 저장과 이어하기
- 스토리: 플레이어로서 앱을 껐다 켜도 하던 곳에서 이어하고 싶다, 그래서 짧게 나눠서 플레이할 수 있다.
- 관련 기능: F10
- 인수 조건:
  - Given 플레이 중 When 지역을 옮기거나 조각을 줍거나 색을 복원하면 Then 자동 저장된다.
  - Given 저장된 기록이 있을 때 When 게임을 다시 열면 Then 타이틀의 "이어하기" 버튼으로 같은 지역·위치·수집 상태로 돌아온다.
  - Given 새로 시작을 고르면 Then 확인을 한 번 받은 뒤 처음부터 시작한다.
  - 저장 데이터에 버전 번호가 있어서, 나중에 구조가 바뀌어도 옛 기록 때문에 게임이 깨지지 않는다.
- 세부 작업:
  - [x] 저장 데이터 구조 설계 (`src/save.ts` — 버전 번호 + 옛 기록 변환(migrate), 알아볼 수 없는 기록은 버림)
  - [x] 브라우저 저장소에 자동 저장·불러오기 (지역 진입·조각 획득·색 복원 시, 걷는 중 3초마다, 앱을 내릴 때)
  - [x] 타이틀 화면 이어하기 / 새로 시작(확인 창)
  - 메모: 보석·펫·지역별 복원 항목은 해당 기능이 생길 때 VERSION을 올리며 추가
- 상태: 구현·배포 완료 (2026-10-10), 폰 확인 대기
