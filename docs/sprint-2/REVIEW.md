## 막힌 것
- 에셋 팩에 여우가 없어 펫 기획을 바꿨다(너구리).
- 타일셋이 자동 연결(오토타일) 구조라 흙길의 꺾이는 모서리 타일은 아직 정확하지 않다 → 직선 길과 사각 공터 위주로 설계해 피했다.
- 개발 서버의 코드 즉시 반영(HMR) 중 남은 오래된 오류 메시지가 콘솔에 섞여 있어 매번 새로 불러와 확인했다.
