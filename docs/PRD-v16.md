## 1. 한 줄 요약
색을 되찾은 물가에서 찌가 쏙 들어가면 탭해 물고기를 낚는다. 계절마다 두 종, 모두 8종을 도감에 모은다.

## 2. 요구사항
| 항목 | 내용 |
|---|---|
| 낚시터 | 봄 들판 연못 · 햇살 해변 웅덩이 · 추수 들판 물웅덩이 · 얼어붙은 호수 얼음 구멍 (잔물결 표시). 흑백일 때는 "색을 되찾으면 물고기도 돌아올 것 같다" |
| 손맛 | 1.5~4초 기다리면 찌가 들어감 → 1초 안에 탭. 너무 빨라도·놓쳐도 벌 없음 |
| 물고기 | 봄 붕어·민물 새우 / 빨간 도미·꼬마 문어 / 은빛 은어·푸른 고등어 / 얼음 빙어·눈꽃 새우. 못 잡은 것이 조금 더 잘 잡힘 |
| 도감 | "물고기" 탭: 잡은 것은 컬러와 잡은 수, 못 잡은 것은 그림자 |
| 보상 | 8종을 모두 낚으면 가구 "낚시 상자" |
