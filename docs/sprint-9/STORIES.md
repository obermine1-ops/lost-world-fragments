# Sprint 9 — 개구리와 숨겨진 섬
- 상태: **완료** (2026-10-10, 자동 진행 모드 — 폰 확인 대기)
- 목표: 바닷가 마을 터에서 개구리 합류 → 연잎 다리 → 숨겨진 섬 → 여름 엔딩.

## 한 일
- 바닷가 마을 터(30×36): 버려진 집·사당·기둥·석상, 우물가 연못(개구리), 산호빛 보석·조각·제단, 흙더미(표주박 물병). 해변을 복원하면 동쪽 길목이 열린다.
- 숨겨진 섬(24×30): 사방이 바다, 큰 나무 아래 제단, 섬의 샘. 바다빛 보석은 땅속(너구리), 흙더미(나무 물고기). 카드 12장 퍼즐, 기억 "처음 바다를 본 날의 나".
- 개구리 펫: 다가가면 합류, 너구리 뒤를 따라온다(줄지어 따라오기). 탭하면 하트.
- **연잎 다리**: 개구리와 함께 물가에 서면 개구리가 뛰어가 연잎이 하나씩 떠오르며 바다 위에 길이 생긴다. 개구리 없이 가면 "물 위를 건널 방법이 없을까". 한 번 놓은 다리는 저장된다.
- 테두리 나무 윗줄도 막도록 바꿔 길목 장벽을 옆으로 돌아가는 틈을 없앰.
- 지도 검사가 개구리·연잎 다리를 이해하도록 확장. 저장 형식 v5(개구리).

## 확인 (브라우저)
- 개구리 없이 물가 → 안내 / 개구리 합류 → 다리 생성 → 섬 이동(두 동물 함께) → 보석 파기 → 조각 → 제단 → 12장 퍼즐 → 기억 → 여름 엔딩 → 요약.
