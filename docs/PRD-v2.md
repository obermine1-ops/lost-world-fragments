# 잃어버린 세계의 조각 PRD — v2 (여름과 나의 집)
- 버전: v2 / 작성일: 2026-10-10 / 상태: 확정
- 기반: [PRD v1](PRD.md) (봄 계절, 완성·폰 테스트 통과)

## 1. 한 줄 요약
봄을 되찾은 뒤 같은 여행이 여름으로 이어진다. 바닷가에서 개구리를 만나 연잎 다리로 **숨겨진 섬**에 건너가 여름의 기억을 되찾고, 봄 들판의 **작은 집**을 모은 것들로 꾸민다.

## 2. 배경
- v1(봄)은 막힘 없이 약 25분에 클리어, "재밌다"는 반응.
- v1에서 미뤘던 것 중 사용자가 고른 것: 여름 계절 + 숨겨진 섬, 집 꾸미기, 펫 더 많이.
- 원칙: 세 가지를 **서로 엮어** v1과 비슷한 규모로 만든다.
  - 새 펫(개구리)이 **섬으로 가는 열쇠**가 된다.
  - 집은 **수집의 목적지**가 된다(도감 = 보는 곳, 집 = 놓는 곳).

## 3. 핵심 흐름
```
봄 엔딩 → "여름으로" → 햇살 해변(흑백) → 바닷가 마을 터 → 개구리 합류
  → 연잎 다리로 숨겨진 섬 → 여름 마지막 기억 → 여름 엔딩
언제든: 봄 들판의 집에 들어가 가구·전시품을 자유롭게 배치
```

## 4. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| V1 | 계절 이어가기 | Must | 봄 엔딩 후 "여름으로"를 누르면 같은 저장으로 해변에서 시작. 봄 들판 남쪽 길(봄 복원 후 열림)로 해변과 오갈 수 있다. 이전 저장(봄 진행 중)도 그대로 이어진다. |
| V2 | 여름 지역 3곳 | Must | 햇살 해변, 바닷가 마을 터, 숨겨진 섬. 지역마다 보석·조각·제단·퍼즐·기억 장면, 지역별 색 복원. |
| V3 | 개구리 펫 | Must | 바닷가에서 만나 합류. 너구리와 함께 따라다닌다. 탭하면 반응. |
| V4 | 연잎 다리 | Must | 개구리와 함께 물가의 표시 지점에 가면 연잎 징검다리가 생겨 건널 수 있다. 섬은 이 방법으로만 갈 수 있다. |
| V5 | 여름 엔딩 | Must | 섬의 기억을 되찾으면 여름 엔딩 글 → "두 번째 계절 · 끝" 요약 화면. |
| V6 | 나의 집 | Must | 봄 들판의 작은 집 문으로 들어가면 실내 방. 방 바닥 칸에 가구·전시품을 놓고, 옮기고, 치울 수 있다. 저장된다. |
| V7 | 가구 얻기 | Must | 지역을 복원할 때마다 가구 1개 + 여름의 흙더미에서 가구. 돈·상점 없음. 이미 봄을 복원한 기록에도 봄 가구가 주어진다. |
| V8 | 전시품 | Should | 도감의 보석·희귀 아이템도 방에 놓을 수 있다. |
| V9 | 여름 음악·소리 | Should | 여름 지역 음악, 물·개구리 효과음. |
| — | 가을·겨울, 상점·화폐, 벽지·바닥 바꾸기, 앱스토어 | Won't (v2) | |

## 5. 비기능 / 제약
- v1과 같음(폰 웹, 서버 없음, CC0 에셋, 세로 화면).
- 저장 형식을 올리며 이전 기록을 자동 변환한다(진행이 날아가지 않게).
- 지도 진행 불가 검사를 연잎 다리까지 확장한다.

## 6. 성공 지표
- 여름까지 막힘 없이 클리어, 여름 분량 약 25~35분.
- 집에 가구를 5개 이상 놓아 보는가(테스터 관찰).

## 7. 가정 (자동 진행 모드에서 Claude가 추천안으로 정함)
- 개구리와 너구리는 둘 다 따라다닌다(붐비면 조정).
- 집은 봄 들판 시작 지점 근처. 실내 방은 9×8칸.
- 여름 기억의 주인공: 바닷가 할아버지(어부), 마을 친구들, 그리고 섬에서 "처음 바다를 본 날의 나".
