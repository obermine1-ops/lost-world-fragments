# 잃어버린 세계의 조각 PRD — v8 (아이폰 친구도)
- 버전: v8 / 작성일: 2026-10-12 / 상태: 확정 (자동 진행 모드 — Claude가 추천안으로 결정)

## 1. 한 줄 요약
지인 테스트를 아이폰으로 해도 음악이 나오고, 기록이 날아가지 않게 한다.

## 2. 왜
- 음악이 모두 ogg — 아이폰 사파리는 ogg를 못 틀 수 있다(그동안 "사람만 확인" 항목).
- 아이폰 사파리는 한동안 안 들어온 사이트의 저장 기록을 지울 수 있다. 홈 화면에 추가하면 안전.
- 폰을 바꾸거나 기록이 지워졌을 때 되살릴 방법이 없다.

## 3. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| I1 | 음악 mp3 사본 | Must | 모든 음악에 mp3 사본(96kbps). 기기가 ogg를 못 틀면 mp3를 받는다. 음량·길이가 원본과 같다. |
| I2 | 기록 백업 코드 | Must | 타이틀 "기록 옮기기" → 백업 코드 복사 / 코드로 불러오기. 기록이 없을 때도 "코드로 불러오기". 망가진 코드는 거부. |
| I3 | 기록 지키기 안내 | Should | 아이폰 사파리(홈 화면 앱이 아닐 때) 타이틀에 "홈 화면에 추가" 안내. 브라우저에 저장 공간 보존 요청(persist). |
