# Sprint 10 — 나의 집
- 상태: **완료** (2026-10-10, 자동 진행 모드 — 폰 확인 대기)
- 목표: 봄 들판의 작은 집 → 실내 방 → 가구·전시품 자유 배치·이동·치우기, 저장.

## 한 일
- 봄 들판 시작 지점 오른쪽에 주황 지붕 집(TilesetHouse). 문 앞에 서면 들어간다. 나오면 문 앞(한 칸 아래)에서 다시 시작 — 바로 다시 들어가지 않도록 "처음부터 근처에 있던 지점은 한 번 멀어져야 반응"하게 바꿈.
- 실내 방 11×9칸(바닥 9×7): 벽(TilesetWallSimple)·마루(TilesetInteriorFloor).
- 상자(아래): 가진 가구 + 도감의 보석·희귀 아이템. 고르고 → 바닥 칸을 누르면 놓기 / 놓인 물건을 누르면 집어 들기 → 다른 칸에 놓으면 옮기기, 상자 칸을 누르면 치우기.
- 가구 11종: 시작(침대·탁자), 지역 복원마다 1개(화분·의자·꽃바구니·책장·어항·평상·버섯 등), 계절을 마치면 1개(봄 그림 액자·비치볼). 이미 복원한 기록에도 바로 생긴다(복원 기록에서 계산).
- 지역을 복원하면 "새 가구를 얻었다" 안내.
- 저장 형식 v6(집 배치).

## 확인 (브라우저)
- 집 들어가기 → 침대·화분·의자 놓기 → 침대 옮기기 → 저장 확인 → 밖으로 → 문 앞에서 재진입 없음.
