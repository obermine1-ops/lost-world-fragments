# Sprint 29 — 계절별 퍼즐 규칙 (물결·바람·눈보라)
- 상태: **완료** (2026-10-12, 자동 진행 모드)

## 한 일
- `PuzzleScene` RULES: 봄 기본 / 여름 "물결"(처음에 모든 그림을 1.8초 + 쌍당 0.2초 보여 줌) / 가을 "바람"(짝을 맞출 때마다 뒤집힌 카드 두 장이 0.52초 동안 기울며 미끄러져 자리 바꿈) / 겨울 "눈보라"(1.2초 + 쌍당 0.15초 보여 준 뒤 바람도).
- 퍼즐 위에 규칙 이름("가을 · 바람" 등), 설명 줄을 규칙에 맞게. 보여 주는 동안·카드가 움직이는 동안은 누를 수 없음.
- 제단에서 여는 퍼즐에 지역 계절을 넘김. 자동 플레이 봇은 보여 주기가 끝날 때까지 기다렸다가 풂.

## 확인
- 가을 5쌍: 짝을 맞추자 바로 입력 잠김 → 두 장이 자리를 바꾸고(좌표 확인) 잠금 풀림. 화면에서 기울어진 채 엇갈리는 모습 확인.
- 겨울 6쌍: 12장 모두 앞면 → 2.1초 뒤 모두 덮이고 입력 가능.
- 자동 플레이 새 게임 → 최종 엔딩 ✅ (3배속 338초, 퍼즐 13개, 창 가림 2초 자동 제외).
