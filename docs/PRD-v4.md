# 잃어버린 세계의 조각 PRD — v4 (겨울과 마지막 기억)
- 버전: v4 / 작성일: 2026-10-12 / 상태: 확정 (자동 진행 모드 — Claude가 v1~v3와 같은 원칙으로 추천안 결정)

## 1. 한 줄 요약
마지막 계절, 겨울. 눈 덮인 숲에서 햄스터를 만나 **눈벽 속 좁은 굴**에 숨은 물건을 가져오게 하며 겨울의 기억을 되찾고, 네 계절을 모두 되찾으면 **최종 엔딩과 크레딧**을 본다.

## 2. 원칙
- 새 펫 = 새 지형의 열쇠: 너구리(땅) · 개구리(물) · 앵무새(하늘) · **햄스터(좁은 굴)**.
- 집: 겨울 가구·반딧불 보상.
- 마지막 계절이므로 게임 전체의 이야기를 닫는다: 도입("무언가 소중한 것을 잊어버렸다") ↔ 최종 엔딩.

## 3. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| X1 | 겨울 이어가기 | Must | 가을 요약 "겨울로", 바람의 언덕 북쪽 길(가을 복원 후). 타이틀 바로 가기. |
| X2 | 겨울 지역 3곳 | Must | 눈 덮인 숲·얼어붙은 호수·별빛 언덕. 눈 바닥·눈 절벽·얼음 호수·눈나무. 보석·조각·제단·퍼즐·기억·반딧불 3. |
