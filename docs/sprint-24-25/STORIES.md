# Sprint 24~25 — 길 안내 발자국, 한 번만 나오는 안내, 글 다듬기 (Z1~Z3)
- 상태: **완료** (2026-10-12, 자동 진행 모드)

## 한 일
- **S24 길 안내 발자국 (Z1)**
  - 화면 위 목표 문구(끝에 ›)를 누르면 지금 목표까지 빛나는 발자국이 차례로 켜졌다 사라지고, 도착점에 빛 고리.
  - 목표: 보석(땅속·절벽·굴 속이면 그 표시) → 조각 → 제단 → 다음 지역 길목.
  - 길이 막혀 있으면 길을 여는 곳으로 대신 안내: 돌무더기 흙더미 → 열쇠가 묻힌 흙더미 → 잠긴 문 → 연잎 다리 물가 ("길이 막혀 있다. 먼저 저곳을 살펴보자").
  - 다른 지역의 친구가 필요하면 "지도로 바로 갈 수 있어요", 다음 계절이 다른 지역에서 이어지면 "지도에서 ○○으로 바로 갈 수 있어요", 반딧불만 남았으면 "가까이 가면 반짝여요".
- **S25 한 번만 나오는 안내 (Z2), 글 다듬기 (Z3)**
  - 처음 한 번씩: 목표 문구 누르기(첫 화면), 지도 버튼(봄 들판 밖 첫 지역), 도감(첫 희귀 아이템). 저장 형식 v11(본 안내 목록).
  - 되찾지 못한 지역에서 1분 30초 동안 진전이 없으면 목표 문구가 살짝 흔들리고 하얗게 빛난다.
  - 글 전체 검토: 이야기 글은 그대로. 도감의 못 찾은 아이템 안내를 가을·겨울(앵무새·햄스터 심부름)에도 맞게, 너구리 안내를 "봄 들판"으로.

## 테스트
- 자동 확인: 13개 지역 × 단계(보석·조각·제단·다음 길) 모두 목표까지 길이 있거나, 막힌 경우(잊힌 유적 3단계, 바닷가 마을 터 연잎) 길을 여는 곳으로 안내됨. 유적은 돌무더기 → 열쇠 흙더미 → 잠긴 문 → 보석 순서 확인.
- 브라우저: 새 기록 → 첫 안내 표시, 목표 문구 탭 → 발자국.
- 회귀: 자동 플레이 봇 새 게임 → 최종 엔딩 완주(3배속 320초), 한 번만 나오는 안내 3개 모두 한 번씩 나옴.

## v6 회고
- 길 안내를 "막힌 길이면 여는 곳으로" 이어지게 만든 것이 핵심 — 유적처럼 순서가 있는 곳에서도 목표 문구만 누르면 다음 할 일로 이어진다.
- 지도 검사·자동 확인 스크립트로 13개 지역 × 4단계를 몇 초 만에 확인할 수 있었다.
- 남은 것: 지인 플레이테스트(사람만 가능). 결과가 오면 막힌 곳 위주로 다듬기.
