# Sprint 26 — 음악 필요할 때만, 소리 균형, 소리 설정 3단계 (P1~P3)
- 상태: **완료** (2026-10-12, 자동 진행 모드)

## 한 일
- **P1** 음악을 시작할 때 12곡 다 받던 것 → 지금 트는 곡만 받고, 바뀌면 이전 곡은 페이드아웃 뒤 메모리에서 내림.
  - 메모리의 음악: 215MB → 한 곡(최대 약 26MB). 처음 받는 양: 14MB → 타이틀 곡 0.4MB.
  - 다시 그 지역에 가면 기기에 보관된 파일(서비스 워커)에서 금방 다시 불러옴.
- **P2** 곡마다 평균 음량을 -20dB에 맞추는 배율(가장 큰 소리가 넘치지 않는 범위), 효과음은 절반만 보정(흙더미 소리 2.2배 등).
- **P3** 소리 버튼 3단계: 소리 켜짐 → 효과음만 → 소리 꺼짐. 효과음만·꺼짐에서는 음악을 받지도 않음(데이터 절약). 예전 "소리 꺼짐" 설정은 그대로.

## 테스트
- 브라우저: 타이틀에서는 music-quiet만, 눈 덮인 숲 → winter만, 햇살 해변 → summer만 남음. 받은 파일도 그 3개뿐.
- 소리 버튼 3번 누르기: 효과음만(음악 멈춤) → 꺼짐(전체 음소거) → 켜짐(음악 다시, 배율 적용 볼륨 0.35).
- 회귀: 자동 플레이 봇 새 게임 → 최종 엔딩 완주(3배속 324초, 내내 59fps 이상, 오류 0).
  - 그 전 두 번은 실패(바람의 언덕·봄 들판 반딧불에서 멈춤) — 그때 게임 루프 프레임이 0이었고, 다시 돌리니 같은 코드로 완주. 미리보기 창이 가려져 브라우저가 화면 갱신을 멈춘 환경 문제로 판단.
  - 봇에 "화면 갱신이 멈춘 시간(stalledSeconds)" 기록을 추가해 다음부터는 바로 구분.
