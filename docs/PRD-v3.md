# 잃어버린 세계의 조각 PRD — v3 (가을과 하늘 친구)
- 버전: v3 / 작성일: 2026-10-10 / 상태: 확정 (자동 진행 모드 — Claude가 v1·v2와 같은 원칙으로 추천안 결정, 사용자 의견은 언제든 반영)
- 기반: [PRD v1](PRD.md) · [PRD v2](PRD-v2.md)

## 1. 한 줄 요약
여름 다음은 가을. 단풍 숲에서 앵무새를 만나, 사람이 오를 수 없는 **절벽 위의 물건을 날아가 가져오게** 하며 세 번째 계절의 기억을 되찾는다. 집은 **벽지·바닥**까지 꾸밀 수 있다.

## 2. 원칙 (v2와 같음)
- 새 펫 능력이 새 지형의 열쇠가 된다: 너구리 = 땅, 개구리 = 물, **앵무새 = 하늘(높은 곳)**.
- 집은 수집의 목적지: 계절을 되찾을 때마다 새 벽지·바닥이 생긴다.
- 규모는 v1·v2와 비슷하게(계절 하나, 지역 3곳).

## 3. 핵심 흐름
```
여름 엔딩 → "가을로" (또는 바닷가 마을 터 북쪽 길) → 단풍 숲(흑백)
  → 앵무새 합류 → 추수 들판(절벽 위 보석을 앵무새가 가져옴) → 바람의 언덕 → 가을 엔딩
```

## 4. 기능 요구사항
| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| W1 | 가을 이어가기 | Must | 여름 요약 화면 "가을로", 마을 터 북쪽 길(여름 복원 후 열림). 이전 기록 그대로 이어짐. |
| W2 | 가을 지역 3곳 | Must | 단풍 숲·추수 들판·바람의 언덕. 낙엽 바닥, 단풍나무, 주황 절벽. 지역마다 보석·조각·제단·퍼즐·기억, 반딧불 3마리. |
| W3 | 앵무새 펫 | Must | 단풍 숲에서 합류, 줄지어 따라온다, 탭하면 하트. |
| W4 | 하늘 심부름 | Must | 절벽 아래 "깃털 표시"에 앵무새와 서면, 앵무새가 절벽 위로 날아가 물건(보석·희귀 아이템)을 물어 온다. 앵무새 없이는 "높아서 닿지 않는다". |
| W5 | 가을 엔딩 | Must | "세 번째 계절 · 끝" 요약. |
| W6 | 벽지·바닥 | Must | 집에서 벽지 4종·바닥 4종 중 고르기. 처음 1종씩, 계절을 되찾을 때마다 1종씩 더. 저장. |
| W7 | 가을 가구·아이템 | Should | 지역 복원 가구 3 + 계절 가구 1 + 반딧불 가구 1, 희귀 아이템 3. |
| W8 | 가을 음악 | Should | 흑백 가을·복원된 가을 음악. |
| — | 겨울, 상점, 앱스토어 | Won't (v3) | |

## 5. 테스트
- 지도 검사(앵무새 심부름·절벽 포함), 자동 플레이 봇으로 새 게임 → 가을 엔딩 완주.

## 6. 가정
- 가을 기억: 낙엽을 함께 쓸던 할아버지, 추수를 돕던 이웃 아저씨, 바람의 언덕에서 연을 날리던 "나".
- 절벽(주황 대지)은 걸어서 오를 수 없다. 위의 물건은 앵무새만 가져올 수 있다.
