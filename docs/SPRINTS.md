# 스프린트 계획
- 상태: 확정 (2026-10-09)
- 스프린트 길이: **목표 단위** (목표를 달성하면 끝, 회고 후 바로 다음 스프린트). 처음엔 2주였으나 Sprint 1이 2일 만에 끝나 변경.
- 투입 시간: 주 3~5시간 (사용자 기준, 코드는 Claude가 주로 작성)
- 기술 스택: Phaser 3 + Vite + GitHub Pages
- 전체: 7 스프린트 (처음 예상 14주 → 실제 속도에 따라 단축 예상)
- 진행: Sprint 1 ✅ 완료 (2026-10-10) / Sprint 2 ✅ / Sprint 3 ✅ / Sprint 4 ✅ / Sprint 5 ✅ 완료 — 콘텐츠 완성 (2026-10-10, 폰 확인·지인 테스트 대기)

## Sprint 1: 걷는 뼈대 (Walking Skeleton)
- 목표 (데모): 폰으로 링크를 열면 타이틀 → 흑백 들판(네모·동그라미 도형) → 탭으로 이동 → 기억 조각 줍기 → 카드 4장 짝맞추기 → 화면에 색이 돌아옴 → "끝" 화면까지 한 바퀴 돈다.
- 포함 범위: F1·F2·F3·F4·F11·F12 (각각 가장 얇은 버전)
- 완료 기준(DoD):
  - GitHub Pages 링크로 사용자 폰(세로 화면)에서 실행된다.
  - 흑백 → 컬러 전환이 폰에서 끊김 없이 동작한다(체감 확인).
  - 코드를 고치고 다시 배포하는 절차가 문서(`docs/HOW-TO-DEPLOY.md`)로 남아 있다.
- 의존성: 사용자의 GitHub 계정 생성
- 예상 규모: M
- 이렇게 구성한 이유: 가장 큰 기술 리스크 세 가지(모바일 흑백 필터 성능, 배포 파이프라인, 탭 이동)를 첫 2주 안에 확인한다. 그림 없이 도형으로 만들어서 에셋 고민 없이 전체 흐름부터 관통시킨다.

## Sprint 2: 진짜 봄 들판
- 목표 (데모): 실제 픽셀 그림으로 된 봄 들판 2~3개 지역을 탭으로 돌아다니고, 앱을 껐다 켜도 이어서 플레이한다.
- 포함 범위: 에셋 팩 확정, F1(완성: 길 찾기 이동·충돌·지역 이동·카메라), F10(자동 저장·이어하기)
- 완료 기준(DoD):
  - 에셋 팩과 타일 크기가 확정되고 `CREDITS.md`에 라이선스가 기록되어 있다.
  - Tiled로 만든 지역 2~3개를 오갈 수 있고, 막힌 곳은 지나갈 수 없다.
  - 위치·획득 아이템이 저장되고, 새로고침해도 유지된다.
- 의존성: Sprint 1
- 예상 규모: M
- 이렇게 구성한 이유: 맵과 타일 크기가 정해져야 이후 모든 콘텐츠를 배치할 수 있다. 저장 구조는 나중에 넣으면 기존 기능을 전부 고쳐야 해서 기반 단계에 넣는다.

## Sprint 3: 복원 루프 완성
- 목표 (데모): 보석을 찾아 제단에 끼우고 → 짝맞추기 → 기억 장면 → 그 지역만 색이 번지며 돌아오고 → 다음 지역 길이 열린다. 지역 2개를 연속으로 복원할 수 있다.
- 포함 범위: F3(완성), F3a, F4(완성: 단계별 카드 수 증가), F2(완성: 지역별 복원·저장), F5(장면 시스템, 임시 그림), F6
- 완료 기준(DoD):
  - 보석이 없을 때 제단에서 힌트가 나온다.
  - 퍼즐 클리어 → 장면(그림 1장 + 대사 2~4줄) → 지역 색 복원 → 길 해금 순서가 매번 올바르게 동작한다.
  - 복원 상태가 저장된다.
  - 기억 장면 그림을 구할 방법이 결정되어 있다(열린 질문 해소).
  - **중간 테스트**: 지인 1명(가능하면 아이폰 사용자, iOS 사파리 첫 확인 겸)이 설명 없이 10분 플레이하고, 반응(재밌어한 곳, 헤맨 곳)을 기록했다. 방향이 틀렸다면 S4 전에 계획을 조정한다.
- 의존성: Sprint 2
- 예상 규모: L
- 이렇게 구성한 이유: 핵심 루프가 이 게임의 재미 그 자체다. 펫·던전보다 먼저 완성해서 "재밌는지"를 가장 일찍 확인한다.

## Sprint 4: 너구리와 도감
- 목표 (데모): 너구리를 만나 동료로 삼고, 함께 다니며 흙더미를 파서 숨은 길과 희귀템을 찾는다. 도감에서 모은 보석·희귀템·기억 장면을 본다.
- 포함 범위: F7, F9
- 완료 기준(DoD):
  - 너구리가 자연스럽게 플레이어를 따라다닌다(길 막힘·겹침 없음).
  - 땅 파기로만 열리는 길이나 보물이 필드에 1곳 이상 있다.
  - 도감에서 얻은 것은 컬러로, 못 얻은 것은 실루엣으로 보이고, 장면을 다시 볼 수 있다.
- 의존성: Sprint 3 (수집·저장 구조)
- 예상 규모: M
- 이렇게 구성한 이유: 던전이 땅 파기를 전제로 하니 펫이 먼저 와야 한다. 도감은 수집품 종류가 다 정해진 이 시점에 만드는 게 가장 덜 고친다.

## Sprint 5: 동굴 유적과 엔딩 — 처음부터 끝까지
- 목표 (데모): 타이틀부터 던전의 마지막 기억 복원, 봄 전체에 색이 돌아오는 엔딩까지 30분~1시간짜리 게임을 끝까지 플레이할 수 있다.
- 포함 범위: F8, F11(완성: 도입·엔딩 연출), 기억 조각 4~6개 전체 배치
- 완료 기준(DoD):
  - 던전에 땅 파기가 필요한 구간이 있고, 마지막 조각과 보석이 있다.
  - 엔딩 후 타이틀로 돌아간다.
  - 사용자가 직접 처음부터 끝까지 진행 불가 버그 없이 클리어한다.
- 의존성: Sprint 4
- 예상 규모: L
- 이렇게 구성한 이유: 모든 시스템이 갖춰진 뒤 콘텐츠를 완성하는 단계다. 여기서 "콘텐츠 완성(content complete)"을 찍고, 이후는 다듬기에 집중한다.

## Sprint 6: 다듬기
- 목표 (데모): 진짜 장면 그림과 다듬은 스토리 텍스트, 사운드가 들어간 "남에게 보여줄 수 있는" 버전.
- 포함 범위: 장면·카드 그림 교체, 스토리 텍스트 다듬기, 길 안내·튜토리얼 보강, 성능 점검(F12 기준), Should(F13 사운드, F14 PWA, F15 펫 교감)
- 완료 기준(DoD):
  - 임시 그림이 남아 있지 않다.
  - 보급형 폰에서 30fps 이상, 첫 로딩 5초 이내.
  - (Should) 사운드·음소거, 홈 화면 설치, 너구리 쓰다듬기 반응.
- 일정이 밀리면 Should를 자르는 순서: ① F14 PWA → ② F15 펫 교감 → ③ F13 사운드 (사운드는 힐링 분위기에 가장 중요해서 끝까지 지킨다)
- 의존성: Sprint 5
- 예상 규모: M
- 이렇게 구성한 이유: 그림·문구는 게임 흐름이 확정된 뒤 바꿔야 두 번 일하지 않는다. Should는 앞 스프린트가 밀릴 때 잘라낼 수 있는 완충 역할도 한다.

## Sprint 7: 지인 플레이테스트
- 목표 (데모): 지인 3명이 설명 없이 폰으로 끝까지 클리어하고, 받은 피드백으로 고친 최종 v1.
- 포함 범위: 플레이테스트 진행·관찰, 막힘 지점과 버그 수정, 성공 지표 측정
- 완료 기준(DoD):
  - PRD 8장의 성공 지표 4개를 측정해 기록했다(`docs/PLAYTEST.md`).
  - 진행 불가 버그 0건.
- 의존성: Sprint 6
- 예상 규모: M
- 이렇게 구성한 이유: PRD의 성공 기준이 "남이 끝까지 하는 것"이라 피드백을 반영할 시간을 따로 확보한다.
